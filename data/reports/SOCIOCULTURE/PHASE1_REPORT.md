## 6. Known limitations

- OCR: 149 questions (2006 6월·수능, 2008 9월, 2009 9월, 2015 6월, 2017 9월, 2025 수능 fully; 2005 9월 Q6/Q14, 2007 9월 7 questions) are image-only/garbled-font → Tesseract text with typical errors (㉠/① misreads, 학→확); choices not structured.
- Old PDFs (2005–2014) have text without word spacing; some fonts map brackets to ġ/Ģ or ~/₩ (handled for [3점] and [N~M]).
- Text inside embedded raster figures is not in the PDF text layer; it is OCR'd separately into `embedded_image_ocr_text`.
- has_visual_material is heuristic (raster image, ≥2×2 table, diagonal strokes/curves, filled shapes); null for OCR questions.
- points: from the official table where transcribed, else the [3점] marker; OCR questions may have points=null; one 2005 수능 [3점] marker is unreadable (total 49).
- 51 exams rely on the 해설 answer summary (no 평가원 정답표 file in the repository for them).
- `28예시` is a 2-byte placeholder (the original 2028 예시 PDF was replaced in commit dd3b206).
- Crops are generous: the last question of an exam can include the '확인 사항' box; this is cosmetic.
